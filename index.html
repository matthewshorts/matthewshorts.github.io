Shorts Studio Assistant

Shorts Studio Assistant is a private desktop tool used by Matthew Ball to prepare short vertical videos about films and TV series for the operator's own YouTube channel: https://www.youtube.com/channel/UC66rh55ymmBTHL7XfOS_RkQ.

The tool writes an original script, generates a voice-over, assembles the video from licensed stock footage and officially published promotional images, and uploads the finished video to the operator's channel.

Use of YouTube API Services

This application uses YouTube API Services to upload videos to the operator's own channel, to schedule their publication, to read view statistics of the operator's own videos, and to read public metadata of popular videos for trend analysis. By using this application you agree to be bound by the YouTube Terms of Service.

The application is not publicly available and has no user accounts other than the operator.
