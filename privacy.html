Privacy Policy

Effective date: October 21, 2026

1. Who we are

Shorts Studio Assistant (the "Application") is a private tool operated by Matthew Ball (the "Operator") for the Operator's own YouTube channel. Contact: matthew.6a11@gmail.com.

2. YouTube API Services

The Application uses YouTube API Services. By using the Application you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Data the Application accesses

  • With the Operator's authorization (OAuth scopes youtube.upload and youtube.readonly): the Operator's channel title and the statistics (views, likes, comment counts) of videos uploaded by the Application.
  • Public metadata of public videos (titles, durations, view, like and comment counts, publication dates) obtained through the API for trend analysis. This data is processed in memory during a single run and is not stored.

The Application does not collect personal information of viewers, does not read comments text, and does not use cookies.

4. How the data is used

Data is used only to upload and schedule the Operator's videos and to decide which topics and formats to produce next.

5. Storage and sharing

The OAuth token and the statistics of the Operator's own videos are stored locally on the Operator's computer. Data is not sold, transferred, or shared with any third party.

6. Retention and deletion

Stored statistics of the Operator's videos are refreshed at least once a day. Public metadata of other videos is not retained. All stored data can be deleted at any time by deleting the Application's local data folder. Access granted to the Application can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions.

7. Changes

Changes to this policy will be published on this page with a new effective date.
